This project aims at creating an automated setup on my mac to rename files (pdf and jpg mainly) according to their content.

The app is the SwiftUI project in NimbleName/ (product name "Nimble Name", entry point NimbleName/NimbleName/NimbleNameApp.swift). The legacy Go prototype lives in go-prototype/ (nameflow.go, config.yaml, prompt.txt), kept for reference.

Read the NimbleName-specs.md file for the LLM and application setup.
Please keep the specs file up to date as we change things.
